# Generated SDKs

This directory is populated by `scripts/sdk-gen/run_all.sh`, `make sdk-gen`, or CI (`.github/workflows/sdk-generate.yml`).

## Layout

| Path | Contents |
|------|----------|
| `openapi/v1/openapi.json` | Merged gateway OpenAPI (export offline or from running gateway) |
| `rest/` | Clients from openapi-generator: `typescript-fetch`, `python`, `kotlin`, `swift5` |
| `grpc/python/` | Python `grpc_tools` stubs from `proto/panopticon/v1/` |
| `proto/panopticon/` | Copy of protobuf sources for C/nanopb and other generators |

## Auth and pagination

REST clients generated by OpenAPI Generator include typed models and API classes. Configure the default client with:

- **Bearer JWT**: set the access token on the generated configuration / API client (see each generator’s README under `sdk/rest/<lang>/`).
- **Retries / pagination**: use generator options and app-specific query parameters as defined in the OpenAPI spec (`limit`, `offset`, etc. where exposed).

## gRPC

Prefer `sdk/proto` + `docs/grpc-nanopb.md` for embedded C. Kotlin/Swift gRPC can be produced with `protoc` plugins using the same `.proto` files.

See also `scripts/sdk-gen/README.md`.
