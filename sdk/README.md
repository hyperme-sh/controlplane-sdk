# Control plane SDK tree

Generated REST clients, the OpenAPI snapshot, protobuf stubs, and hand-written auth examples live in this directory. Install and call them from the repository [README](../README.md). The Python distribution built at the repository root is `controlplane-sdk` 0.2.0.

Generation commands are in [scripts/sdk-gen/README.md](../scripts/sdk-gen/README.md). Auth helpers are in [auth/README.md](auth/README.md).
